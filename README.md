# 試卷工作台

將含答案欄的公告試題 PDF 轉成可校對、發布、作答與統計的個人考試網站。PDF、附圖、草稿與作答紀錄全部保存在目前瀏覽器的 IndexedDB，不會上傳到伺服器。

## 本機使用

```powershell
npm install
npm run dev
```

依終端顯示的本機網址開啟網站，再按「匯入 PDF 試卷」。

正式建置：

```powershell
npm run build
npm run preview
```

## 操作流程

1. 匯入含文字層的 PDF。
2. 在校對工作區修正題目、選項與答案；單選及複選配分可分別設定並一次套用整份試卷。
3. 題目提及附圖或包含圖像選項時，系統會自動截取題目黑框；仍可在右側原始卷面重新拖曳框選。
4. 所有警告清除後發布考試。
5. 作答並送出；結果頁會顯示總分與完整錯題。
6. 從題庫開啟「歷次成績與錯題統計」。

題庫頁提供「匯出完整備份」與「匯入備份」。JSON 備份包含全部試卷、原始 PDF、附圖、作答草稿及歷次成績；匯入前會驗證格式並提示確認，還原後會取代目前瀏覽器中的全部資料。

已匯入過的舊題庫可在校對頁按「重新解析原 PDF」，套用最新的跨頁與自動裁圖規則。

複選題必須與標準答案完全一致才得分，少選、多選或錯選均為 0 分。

## 部署

專案已包含 `vercel.json`。將此資料夾匯入 Vercel 後，以 `npm run build` 建置並發布 `dist` 即可。部署後的資料仍只存在每台裝置自己的瀏覽器，不會跨裝置同步。

## 驗證

```powershell
npm run test
npm run build
```

測試會直接讀取工作區內的 `115-1公告試題_I21-5101 資訊安全規劃實務_20260423104227.pdf`，驗證 18 頁、40 題、30 題單選、10 題複選與預設總分 100 分。
